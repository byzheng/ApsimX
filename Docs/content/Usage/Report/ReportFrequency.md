## Create Report Model

A `Report` model can be created into a `Zone` (i.e. `Field`) through context menu `Add model...` in right click of `Zone` node. Users can update two fields to specify `Reporting variables` and `Reporting frequency`.

### Reporting frequency

The `DataStore` or `Report` will be updated based on events in APSIM NG. 


e.g. `[Wheat].Harvesting` to report at harvest, `[Clock].DoReport` to report at end of day.
